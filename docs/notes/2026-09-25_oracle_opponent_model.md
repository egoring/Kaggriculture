# ORACLE 상대 모델 (v8.65 → v8.68, 9/24~25)

## 요지
필드 절반 이상이 공개 m2965 계열 복제본(0~144 유닛이 m2965·v55·v56·v57·W20v41 전부 동일, 94%). 우리 파일 안에서 공개 스택을 두 번째 인스턴스(오라클)로 실행해 상대 행동을 재현하고, 그림자 엔진 한 스텝 + 오라클 상태 스냅샷/복원으로 상대의 **다음 스텝 매도를 미리 알고 한 스텝 먼저 판다**.

## 버전
- v865: 정확 복제본에만 유효. 실전 116판: 현금 $1~10 불일치 3회로 일찍 off → 복제본 36/48(75%).
- v866: 현금 ±60·재고 4 허용, 48스텝 창 6회 초과 off, 재고 편차로 상대 창고 보정.
- v867: 예측 채점(t+2에 시장 흐름으로 상대 매도량 역산) → 최근 12건 적중률 ≥50%일 때만 선매도.
- v868 = v867 + 하드/소프트 off 제거(행동은 적중률 게이트만).

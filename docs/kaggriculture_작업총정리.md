## 2. 핵심 발견 (게임 메커니즘)

- kaggle-environments 1.32.7. 시장은 주문 인덱스별 락스텝 처리(`_process_market`: 양 플레이어의 같은 인덱스 유닛을 짝지어 견적 후 체결). SELL은 price(inv), BUY_PRODUCT는 price(inv−1).
- **wash trade**: 같은 스텝 BUY_PRODUCT WHEAT N + SELL WHEAT N. 혼자 하면 무료. 상대가 (SELL1,BUY1)[G3 대본]이면 큰 wash가 스텝당 +3/−3, 상대가 (BUY1,SELL1) 라이브면 BUY-first wash는 손해(1~3), 큰 BUY-first wash 복제본(router938류)에는 작은 wash(5)가 +11/−10. D0 종료 현금이 $0~40 칼날이라 ±3/스텝이 소 구매/급식 실패로 ±30k로 증폭.
- 상점은 4스텝마다 소비. 자정 재고 자동 폐기(창고 100 초과분). 일손은 매일 리셋(고용비 fib(n)). 밀은 수확량 1에서 시작, 2~4령에 물 주면 +1(비료 +2, 비료 3일 지속, 최대 6). 동물 케어 보너스, 2일 미급식 시 탈출.
- 상대 판별: 1스텝 상대 돈 2630 = 13밀 오프닝(r938 계열과 reactive 모두 동일 → 구분 불가), 2106 = 30오프닝, 3000 = 무주문. 2스텝 복제본 시그니처 984(씨앗 포함)/1054(무씨앗). 3스텝: r938 계열 돈 984~1012 + 농부 [3,3], reactive 돈 1056 + 농부 [4,4] + 일손 5, bharat 일손 4.
- **2스텝 라우팅**: r938와 bharat은 1스텝 농부 행동이 달라(NORTH vs PICKUP WHEAT 2) 단순 지연은 붕괴(농부 위치가 일손 스폰 타일 순서를 바꿈). 해법은 6-1: 농부 지연+일손 순열, 또는 1스텝이 동일한 r938↔reactive 조합(v8.33).
